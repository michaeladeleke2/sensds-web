PCA Comparison

      

      
Dataset Status

      

      

      
      
      

      
This compares two ways of describing the same capture:

• Doppler domain: the spectrogram, ex. how fast things moved.

• Range domain: the range FFT profile, ex. how far away things were.

Both are reduced to 2D with PCA. The one whose classes form tighter, more separated clusters is the better representation for telling these gestures apart.

      

      
💡

      
      
      

    

    

      
Measuring:  Doppler spectrogram amplitude  ·  32x32 resized  ·  1024 features  ·  units dB

      

      

      

      
Measuring:  range profile magnitude + phase  ·  32x32 each  ·  2048 features  ·  units linear amplitude and radians (phase dominates the variance)

      

      

      

      
Run the analysis to compare the two representations.
